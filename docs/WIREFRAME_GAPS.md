# Wireframe vs. site — open gaps

Compared on 2026-11-03 against the "Pampera Website Wireframe" (homepage, launch version).
Parked for later; nothing here has been built yet.

## Decisions needed first

| | Wireframe | Site today |
|---|---|---|
| Shopping | Pre-launch: no prices or cart, "Notify me" buttons | Full store: prices, cart, product pages, checkout once Shopify is connected |
| Edition size | One of twenty per run | 5 per design (3 driver + 2 fairway) |
| Sizes | Driver / Fairway / Hybrid | Driver and Fairway |
| Structure | One scrolling page | Home, Shop, product pages, Story, Shipping |
| Header | Wordmark left, links right, "Join the list" button | Centered logo, links left, cart right |
| Email / inquiries | Shopify newsletter form, Klaviyo later | None |

Suggested approach: a launch-mode switch that hides prices and cart and shows
"Notify me" on product cards, so the shop can open without a rebuild.
